# CeylonGo
Web-based Tour Guide System for Sri Lanka

About the Project

This is a web-based tour guide system developed for the SE2030 Software Engineering module. The main purpose of the system is to provide tourists with one place where they can find destinations in Sri Lanka, plan their trips, find local tour guides and make bookings.

The system is mainly designed for tourists, local tour guides and administrators.

Main Features

The system includes the following main functions:

Destination Search & Discovery

Search and browse destinations in Sri Lanka

Filter destinations by category, location and popularity

View destination information, images, opening hours, entry fees and map location

Itinerary Planner

Create a personalised travel plan

Add destinations, guides and activities

Edit, reorder, save and delete itinerary items

Booking & Reservation Management

Select a tour guide, date and time

Send booking requests

View booking status

Guides can accept or reject booking requests

Reviews & Ratings

Tourists can rate and review destinations and guides

Display ratings and reviews

Allow inappropriate reviews to be flagged for admin review

Local Guide Connect / Messaging

Tourists can communicate with local guides

View guide information such as languages, specialities and experience

Admin Dashboard & Content Management

Manage users, guides and destinations

Verify tour guide accounts

Manage and moderate reviews

View basic booking and platform statistics

Other Features

The system will also include:

User registration and login

Logout

Password reset / forgot password

User profile management

Profile photos

Booking notifications

Search filters and sorting

Basic form validation

Technologies

Frontend: Web technologies

Branch Usage

main - Final version of the project.

development - Main development branch where all members' work is combined and tested.

feature/* - Each member works on their assigned feature using a separate branch.

Members should not directly push their work to main. Completed work should be pushed to the relevant feature branch and then merged into development.

Users of the System

Tourists

Tourists can search for destinations, create itineraries, find tour guides, make bookings, communicate with guides and leave reviews.

Local Tour Guides

Tour guides can create their profiles, receive booking requests, manage bookings and communicate with tourists.

Administrators

Administrators can manage the system, verify guides, manage destinations and users, moderate reviews and view system statistics.

Project Limitations

This is a web application and a native mobile application is not included.

Payment processing will be simulated for the project.

The initial database will contain a selected set of Sri Lankan destinations rather than every destination in the country.

The system will mainly use English content.

The project will be developed using Java-based web technologies within the semester timeframe.
